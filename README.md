## Description

A simple Task Manager web app built with HTML, CSS and JavaScript. Tasks are stored in a Supabase (PostgreSQL) database and accessed through the Supabase REST API using `fetch()`.

Features:

- Display all tasks
- Add a new task
- Edit an existing task
- Mark a task as completed / incomplete
- Delete a task
